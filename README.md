# 🌙 BabySchlaf – Setup Anleitung

## Schritt-für-Schritt auf GitHub hochladen

### 1. GitHub-Account erstellen
→ https://github.com/signup
Kostenlos registrieren mit deiner Google-E-Mail.

### 2. Neues Repository erstellen
1. Oben rechts auf **"+"** klicken → "New repository"
2. Name: `babyschlaf` (oder beliebig)
3. **"Public"** auswählen (nötig für kostenloses Hosting)
4. Auf **"Create repository"** klicken

### 3. Dateien hochladen
1. Auf der Repository-Seite: **"uploading an existing file"** klicken
2. Alle Dateien aus diesem ZIP hierher ziehen:
   - `index.html`
   - `manifest.json`
   - Den Ordner `.github/` (mit dem `workflows`-Unterordner)
3. Unten auf **"Commit changes"** klicken

### 4. GitHub Pages aktivieren
1. Im Repository oben auf **"Settings"** klicken
2. Links in der Seitenleiste: **"Pages"**
3. Unter "Source": **"GitHub Actions"** auswählen
4. Fertig! Nach ca. 1-2 Minuten läuft die App.

### 5. URL deiner App
Die URL lautet:
`https://DEIN-BENUTZERNAME.github.io/babyschlaf/`

Diese URL auf dem Tablet im Browser öffnen.

---

## Als App auf dem Tablet installieren

### iPad / iPhone (Safari)
1. URL im Safari öffnen
2. Unten auf das **Teilen-Symbol** (Quadrat mit Pfeil) tippen
3. **"Zum Home-Bildschirm"** wählen
4. Fertig – die App hat jetzt ein Icon wie eine echte App!

### Android (Chrome)
1. URL in Chrome öffnen
2. Oben rechts auf **drei Punkte** tippen
3. **"App installieren"** oder **"Zum Startbildschirm hinzufügen"**
4. Fertig!

---

## Was die App kann

- 😴 **Schlaf tracken** – Start/Stop mit Live-Timer
- 🍼 **Mahlzeiten erfassen** – Menge und Art
- 📊 **Statistiken** – Charts für Schlaf & Ernährung
- 🔮 **Prognosen** – ab 10 Schlafphasen (Muster-Erkennung)
- 📏 **Wachstum** – Gewicht, Größe mit WHO-Perzentilen
- 👶 **Babyprofil** – Name, Geburtsdaten, Alter
- 📥 **Export** – Alle Daten als JSON-Download
